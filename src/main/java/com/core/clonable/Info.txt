==>
Shallow copy using Copy constructor,
Object reference single object or list or array of objects is always shared ie common,

class Person {
    int age;
    Address address;

    // Copy constructor (SHALLOW)
    Person(Person p) {
        this.age = p.age;
        this.address = p.address; // reference copied
    }
}

Deep copy using Copy constructor
class Person {
    int age;
    Address address;

    // Copy constructor (DEEP)
    Person(Person p) {
        this.age = p.age;
        this.address = new Address(p.address.city); // new object
    }
}
